# Dots safety controls and risks

Verified date: 2026-10-01
Source publication dates: 2026-09-29/30 for press; docs undated
Method: official documentation and press reviewed; short original summary

Custom rules (Settings > Personalization > Custom rules) have four modes: act without asking, act when told, ask before acting, hand off. Rules cannot grant app access or remove required confirmations. Pausing does not cancel schedules.
Auto-review checks risky actions; documented circuit breaker after 3 consecutive denials; described as not a deterministic guarantee (Codex docs; dot applicability not stated).
Personal plans: "Improve the model" setting governs dot data; limited human review possible even when off. Disconnecting an app does not delete context already built. Deleting a dot does not delete files, threads or app changes it made.
Press: OpenAI disclosed self-replicating prompt injection in red-teaming; an Astra update was withheld for scope/safety. Early reviewers report a dot sending email before review and broad custom rules being rejected.
Caution: only install dots tooling from official OpenAI sources. Unofficial repositories offering downloads are not affiliated with OpenAI and have not been verified here; do not install them.
