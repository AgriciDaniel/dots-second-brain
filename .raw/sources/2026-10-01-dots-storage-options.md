# Durable storage and retrieval options for the vault

Verified date: 2026-10-01
Source publication dates: unknown
Method: official and project documentation reviewed; short original summary

Cloud computer keeps its own files and state between use; no retention guarantee is documented.
Google Drive sync requires a Google Workspace domain; gmail.com and googlemail.com are not supported, so it does not fit personal Gmail accounts.
ChatGPT Library offers file storage with automatic Library search (100 GB stated for Pro by help article).
The ChatGPT GitHub app searches live and is read-only; it does not create a synced index.
Obsidian Git can commit, pull and push on an interval. ChatGPT cannot run local stdio MCP servers; remote HTTPS or Secure MCP Tunnel only.
