# Dots context, notes and saved schedules

Verified date: 2026-10-01
Source publication dates: unknown
Method: official documentation reviewed (raw .md page); short original summary

A dot starts with relevant ChatGPT memory and keeps its own notes about preferences, decisions and ongoing work; notes are separate from ChatGPT memory and not a full transcript.
A new task receives instructions and context from the dot for that work only, not every prior conversation. Implication for this vault: the vault path and read order must be passed inside each task and schedule prompt.
Saved schedules: specify what to check or update, when (time zone, end date), which changes deserve a notification, where to deliver results. Event triggers work where a connected service supports event monitoring. Proactive research is limited to what the dot may read; it keeps private notes.
For cloud coding work, create the Codex environment first with repository and setup.
