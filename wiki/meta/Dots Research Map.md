# Dots Research Map

## Gap status · 2026-10-01
- Automatic context loading: not documented. New tasks get only the context the dot passes. Proposed: standing rule in dot notes plus vault path in every task and schedule prompt. Reliability unverified.
- Runtime skills: documented route is a plugin installed and enabled for the account; local skills need a connected computer. Personal-plugin use in a dot unverified.
- Scheduled refresh: documented via saved schedules (what, when with time zone, notify rule, delivery).
- Durable storage: no retention guarantee. Proposed: GitHub repo plus Obsidian Git; Library mirror. Drive sync not available for personal Gmail accounts.
- AGENTS.md auto-read: documented for Codex and Codex cloud environments only.
