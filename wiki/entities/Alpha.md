# Alpha

Alpha is the dot this vault was built for, running on its own [[Dot Cloud Computer]]. The vault is Alpha's source-backed second brain: Alpha reads it by [[Scoped Retrieval]] when a task relates to its projects, decisions or dots knowledge.

- It is not model memory and does not load automatically; see [[Can a dot load this vault automatically]].
- Alpha follows the rules in `AGENTS.md` at the vault root.
- Open setup proposals for Alpha: [[Which dots setup proposals to adopt]].

Rename Alpha freely if you fork this vault for your own dot.
