# Obsidian

The Markdown editor this vault is built for. Notes are plain local files, so an agent can read and edit them directly and Obsidian picks up the changes. This vault uses only core plugins (Properties, Backlinks, Outline, Graph, Canvas, Bases) and runs in Restricted mode.

Conventions: [[Vault Guide]]. Durability: [[Vault Durability and Backup]].
